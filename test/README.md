# 测试目录

`npm test` 发现 `test/**/*.test.mjs` 和 `tests/*.test.mjs`，然后运行四项 workerd 原生检查。`**` 同时覆盖根目录和领域子目录，因此现有根目录并发测试不会遗漏。Python 插件测试仍独立位于 `api_plugin/`。

- `architecture/`：依赖方向、浏览器边界、来源与构建入口。
- `api/`：旧接口、v1、鉴权、签名和渲染契约。
- `query/`：查询引擎、缓存、任务创建和策略兼容矩阵。
- `history/`：历史存储、迁移/回退、分析、缓存和浏览器同步。
- `events/`：赛事、补查、公平调度、提醒与 Web Push。
- `release/`：独立宿主、发布预检、Nginx、同步和发布验证。
- `services/`、`plugin/`、`web/`：纯计算、Bot 构建和网页行为。
- `helpers/`：内存存储、事务回滚以及共享任务环境/额度账本/请求/上游夹具。

根目录的赛事、查询和分析夹具继续被运行时检查和诊断脚本引用；JSON golden 文件保留原位置。`tests/` 保留独立打包和发布边界的集成测试。
