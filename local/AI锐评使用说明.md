# AI锐评 · 谁尽力谁犯罪？

先查询对局，再选择场次，点击“生成锐评”。没有配置密钥时会弹出密码填写框，请填写官方 DeepSeek API Key；加密保存后接着生成。也可点“密钥设置”替换或清除。密钥用 Windows 当前账户加密，重启仍可用，不会回填、导出或打包。

默认主角为查询账号，使用全场双方英雄与表现数据，不受图表玩家范围影响。其他玩家用队伍和英雄称呼，不把完整战网标签发送给 DeepSeek。查询和切换场次仅检查本机缓存，不自动调用模型；“重新锐评”才强制重新生成。该功能会消耗你的 DeepSeek API 额度。

模型为官方 `deepseek-flash`（当前 DeepSeek V4.1 Flash），开启思考模式，思考强度 low，提示词建议100—150字；模型实际输出不做字数、格式或用词过滤，也不自动改写或补齐。评分程序按职责定位与每10分钟指标比较，模型只接收本局累计数据、真实时长和已有评分，再结合胜负、存活、收尾、治疗和抵挡等评价，不强行抓战犯。缺失数据不是0，英雄不代表核验的最长使用英雄。

锐评只在网页展示，不加入强度图或原始数据导出，也不改变评级、强度或个人预测。缓存按账号、场次、数据、模型和提示词版本隔离，存于 `.private/ai-reviews`；私有文件无法通过网页访问。旧锐评在模型失败时保留。鉴权、余额、限流、超时提示不会展示服务商原始响应或密钥。

无对局详情、有效时长或本人记录时暂不能生成。请求超时30秒，思考与正文合计 token 预算4096；一次生成只发起一次模型请求，不因字数或格式再次收费；空正文或接口失败需手动重试。

“娱乐功能仅供参考”：面板无法解释全部比赛行为，锐评与表现分都不是官方结论或真实段位证明。

资源数据包括受治疗与承伤，模型同时收到资源效率修正与定位参考。“吃草挤奶”等表达须结合贡献和存活，受治疗来源未知不能断言都是队友资源。

提示词 v1.4 移除口吻要求、用词范例和娱乐结论引导，仅说明分析任务与数据口径。措辞由模型自行组织，输出仍不做字数、格式或用词过滤。旧版本缓存不会用于新模板。

提示词/数据版本 v1.5：AI请求移除 per10 战斗数字和平滑 K/D，仅发送本局真实累计值；资源参考只发送相对倍数，不发送每10分钟参考总量，避免把归一化值误读为真实击杀、阵亡或治疗。旧模板锐评缓存不用于新请求。内部评级的每10分钟算法不变。

版本 v1.6：每次请求附加《AI锐评-游戏常识.md》全文，区分快速推车目标进度、攻守和竞技换边规则；胜负以查询账号视角 result 为准，不依据2:0推断翻盘。开启 thinking 并使用 reasoning_effort=low，仅显示 content，不展示 reasoning_content。常识文档内容变更会自动改变缓存指纹。
