# 狸狸天眼查 API · AstrBot 插件

这是网站 API 客户端，使用网站账户密钥，无需大神凭证或 Node.js。支持 AstrBot 4.9.2—4.x / Python 3.10+。默认发送图片，需要本机 Playwright Chromium 和中文字体；不使用外部出图服务。

Linux／Docker 安装依赖（Docker 在 AstrBot 容器内执行）：

```sh
python -m pip install 'playwright>=1.49,<2'
python -m playwright install --with-deps chromium
apt-get install -y fonts-noto-cjk
```

生产 Docker 请把这些步骤加入自己的镜像构建，容器重建后也需要具备依赖；仅重启容器不影响已安装依赖。

在 AstrBot 插件页上传 ZIP，在配置中填写 `api_base` 和独立 free 层级的 `free_api_key`。默认地址为 `https://106.55.47.68:8443`。密钥从网站账户的 API 面板获得，插件安装包不包含密钥。换密钥后保存插件配置并重载。该配置 Key 只为未绑定者提供免费服务，必须属于独立 free 层级账号，与个人／管理员账号的额度完全分开；服务账号总额度默认查询／锐评各 1000 次/天。旧 `api_key` 字段不会作为免费服务回退。已绑定者使用自己的 Key，并扣除其所属网站账户额度。`free_daily_limit` 和 `free_review_daily_limit` 分别配置每位发送者每天免费查询／锐评次数，默认各 10 次，支持 0—1000，0 为禁用；按北京时间零点重置。

## 查询指令

```text
/owqs 帮助
/owqs 绑定 owqs_开头的网站Key（仅私聊）
/owqs 查询
/owqs 查询 另一个昵称#67890 5 快
/owqs 查询 20 慢
/owqs 数据 1
/owqs 锐评 10
/owqs 解绑
/owqs 取消
```

昵称可含空格，场数和快慢模式放在昵称后。默认查 10 场、快模式，发送最近 10 场强度图。统计采用网站已有评分，不在 Bot 重算。绑定按平台适配器、机器人和发送者隔离；同一机器人的群聊和私聊共用该发送者绑定。Key 绑定前通过只读接口验证，格式错误或网站拒绝时统一提示“绑定错误，请上网页版确认”，不回显 Key、不替换已有有效绑定，也不会自动使用免费服务代替失效的个人 Key。绑定者可省略 ID，优先使用其上次成功查询的 ID；本地无记录时读取该 Key 所属网站账号的上次查询 ID。未绑定者每次查询必须填写完整游戏 ID，不能隐式复用 ID。出图失败时使用同次查询的文字摘要，不重新查询或重复扣额度。

`数据 n` 和 `锐评 n` 使用**当前发送者最近一次查询图**的窗口，从左到右编号：1 是最左边，10 是最右边（通常是最新一场）。若只有 5 场，只接受 1—5；不会把图以外的对局混进来。新查询图片生成成功后窗口会替换；出图失败时保留上一张图的编号，插件重载会保留最近窗口。首次升级后先查询一次；查询记录过期（完成后约一小时）需重新查询。

数据图展示该局已有的双方击杀／助攻／死亡、伤害、治疗、抵挡、受治疗、承伤等数据，不重新查询战绩、不消耗 AI 额度。锐评沿用网站 DeepSeek 配置：已绑定者使用自己的网站 AI 额度，未绑定者使用免费服务 Key 的网站 AI 额度并受本地免费锐评次数限制，仅在显式请求时生成；相同内容在缓存有效时复用，不重复扣额度。失败释放网站 AI 额度。长锐评拆页发送。最近窗口按发送者隔离，与 Key 绑定一样在同一机器人的群聊和私聊间共用。

## LLM 工具

- `owqs_events(from_date="", to_date="", region="", tournament="", team="", status="scheduled", limit=10)`：查询 OWCS 服务器缓存，支持北京时间日期范围、赛区、赛事关键词、战队名称／简称、赛程／赛果筛选，最多 20 场。无需游戏 ID，不扣查询／AI 或本地免费次数，不触发同步。返回文字赛程，明确提示每日更新，不能当作实时比分。
- 指令示例：`/owqs 赛程 赛区=中国 战队="All Gamers" 开始=2026-10-18 结束=2026-10-20 状态=赛果 条数=5`。所有条件可省略，状态可选赛程／赛果／全部，含空格的值用双引号包住。

- `owqs_query(battletag="", limit=10, mode="fast")`：创建网站查询、等待结果，直接向当前会话发送强度图，并向模型报告已发送；未提供昵称时仅已绑定 Key 者可以使用上一次查询 ID。出图失败时发送文字摘要。
- `owqs_bind()`：提示用户在私聊中用指令绑定网站 Key，不接收或向模型返回 Key。
- `owqs_cancel()`：取消当前发送者的查询。
- `owqs_match_data(n)`：发送最近查询图中第 n 场的数据图片。
- `owqs_match_review(n)`：用户明确要求时生成／复用第 n 场 AI 锐评并发送图片；最多 5 个请求等待，同一发送者一个，插件串行发起 AI 请求。

使用支持工具调用的模型，并在相关会话配置中启用这些工具。可说“帮我查 昵称#12345 的守望先锋战绩”或“查一下我上次查询的守望账号”。模型不能编造战网编号。工具不向模型返回 API 密钥、签名历史或其他玩家的完整名单。

## 任务与错误

插件最多保留 5 个排队/运行中的请求，每位发送者一个，同时向网站运行最多 3 个。网站另外限制每个 API 密钥最多 5 个未完成查询。API 创建请求不自动重发；网站限流暂停时持续轮询现有任务。取消、超时和插件卸载会请求服务端取消未完成任务。网络中断导致取消请求无法到达时，网站仍按原有任务过期规则处理。

网站返回 401/403 时检查密钥和账号授权；429 时检查额度或未完成查询。API 仅允许 HTTPS，拒绝自动跟随重定向，避免将密钥转发到其他地址。配置文件和 `data/plugin_data/astrbot_plugin_owqs_api/bindings.sqlite3` 仅供管理员访问，不要提交或公开。

插件轮询 `/api/v1/jobs/{id}?render=svg&compact=1`，获取内嵌公开素材的 SVG 和精简分析，不传输原始阵容、签名历史或密钥给出图浏览器。浏览器断网渲染，拒绝脚本、外部链接和超大 SVG。PNG 保存在私有 `plugin_data/astrbot_plugin_owqs_api/images` 目录，下次出图时清理超过 24 小时的图片。

## 从仓库打包

```sh
node scripts/build.mjs
python scripts/build-api-plugin.py
python -m unittest discover -s test/api_plugin -v
```

输出 `dist/astrbot_plugin_owqs_api-1.4.2.zip` 及 SHA-256。只打包固定白名单源码、依赖声明和配置 Schema，不打包真实配置、绑定或网站数据。该插件与仓库中的大神直连版 `astrbot_plugin_owqs` 独立维护；避免同时开启两个插件的同名 `/owqs` 指令。

数据图和锐评图复用网页构建产物中的原始 HTML、CSS、逐场玩家渲染函数；网站构建时自动生成 website.json，插件在断网 Chromium 中截图。数据图展示网页原有的完整 14 列、强度依据和评级；锐评保留网页橙色卡片和文字排版。宽表完整出图，长锐评分页。升级需同时更新网站接口和插件。


## 本地数据与云端历史

每个发送者的 Key、上次游戏 ID、最近查询定位、免费计数和免费锐评缓存保存在 Bot 私有 SQLite 文件（目录 0700、文件 0600），与网站云端历史同步独立；切勿公开该目录。旧版昵称绑定不会当作 Key，升级后需要重新私聊绑定。换绑或解绑会清除旧查询窗口与缓存，避免错用账号；免费次数不因解绑、换绑或重启而清零。

免费查询发送 `syncHistory:false`：不读写云端同步历史、不更新网站默认游戏 ID，也不读写跨查询的账号缓存。网站仍保留约一小时的私有临时任务和签名结果，用于数据图和锐评；正常的有界锐评缓存用于避免重复 AI 消耗。绑定者正常同步至 Key 所属网站账号。Bot 本地绑定与免费次数从不参与该同步。

免费次数先原子预留；明确失败或被网站拒绝时释放，已完成查询即使出图失败仍算一次。网络中断或超时导致远端结果不明时保留预留，避免通过反复重试绕过次数限制；不会自动重复创建付费任务。已有免费锐评可在次数用完后继续读取，不重复扣次数。数据图不占查询或 AI 次数。

独立服务器管理员可停服后运行 `node server/provision-free.mjs /绝对路径/astrbot_plugin_owqs_api_config.json`，创建或复用 `bot-free@owqs.invalid` 服务账号并私密写入配置。命令不打印 Key，不修改个人账号。服务端强制 free 层级 Key 的查询不写云端历史；插件也拒绝将其绑定为个人 Key。完成后启动网站并重载插件。

自然语言查询会保留消息中完整游戏 ID 的原始大小写。模型参数支持 10 / 10.0 / "10" 等等价场数与快／慢别名。大神精确搜索无结果时，同一任务内最多尝试四种有界大小写写法，仅接受接口确认完整昵称和编号相同的结果；不模糊匹配、不改编号。未找到玩家时返回核对 ID 的具体提示，失败释放原有额度，不让模型盲目重试。
