Bot 查询 API

供你自己的 Bot 后端通过 Bearer 密钥调用，不开放浏览器跨域直连。

重新生成后旧密钥立即失效。同一账号各端共用额度：获取新数据的成功查询扣 1 次；纯缓存查询、查看历史和重绘不扣。失败、取消或超时释放预占额度。

接口说明

POST /api/v1/query：提交查询，使用 Authorization: Bearer <密钥>，返回任务 ID。

GET /api/v1/jobs/<任务 ID>：读取状态与结果。完成后返回原始对局数据和分析，并自动写入本账号历史。

请求体示例：{"battletag":"昵称#12345","limit":10,"mode":"fast","statisticsRange":"all"}
